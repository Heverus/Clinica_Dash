1 Modelo de dados

Estrela com quatro dimensões e uma tabela de fatos. Cada linha de fato_consultas é um atendimento agendado.

  • dim_medicos · quem atende
  • dim_pacientes · quem é atendido
  • dim_procedimentos · o que é feito
  • dim_convenios · como é pago
  • fato_consultas · valores, tempos e status

2 Camada de consumo

A aba vw_consultas é a visão achatada: nomes já resolvidos, uma linha por atendimento. É ela que alimenta este painel.

  • Publique apenas essa aba como CSV
  • Cole o link em CSV_URL no código
  • Sem link, o painel usa a base de exemplo

3 Como atualizar

Editar a planilha não muda o painel na hora: ele lê o CSV e guarda 5 minutos de cache.

  • Atualizar força nova leitura
  • Cálculo refeito no navegador
  • Nenhum dado sai do seu computador
